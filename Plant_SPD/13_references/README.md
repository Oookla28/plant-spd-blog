正文使用核心理论与方法；早期融合、RMT/估计、相关样本及反事实文献放对应相关工作或附录。原数据来源的正式出版和作者预印本版本分别说明，不能据新文献页面改写既有研究划分。

公开可得、下载完成、摘要核对、章节/公式核对、全文阅读、实现复现是不同状态。本库保留这些区别。未取得公开PDF的条目给官方入口，不放不明来源替代稿。
